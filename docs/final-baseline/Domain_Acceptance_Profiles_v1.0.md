# Domain Acceptance Profiles v1.0

These are candidate package-level domain checks. Select a check only when it applies to the exact skill outcome; never inherit all package checks blindly. Each skill needs its own independent fixtures and expected outputs. The companion skill JSON corrects supplier due-diligence and invoice-reconciliation checks that previously inherited an unrelated cash-flow rule. These checks are unexecuted. Catalogue count does not establish completeness.
