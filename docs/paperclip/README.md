# Paperclip execution pack

This directory is the operator-facing handoff for running the AI Engineering CoE Artifact Factory in Paperclip.

Use the documents in this order:

1. `AI_Engineering_COE_Paperclip_Runbook_v1.0.md` — install Paperclip, connect ChatGPT/Codex and Claude subscriptions, create the company, and start work.
2. `AI_Engineering_COE_Paperclip_Company_Requirements_v1.0.md` — final execution requirements and acceptance contract for the Paperclip company.
3. `AI_Engineering_COE_Paperclip_Role_Mapping_v1.0.md` — the initial company org chart, adapter assignments, authority boundaries, and hiring sequence.
4. `../../paperclip/bootstrap/BOARD_KICKOFF_TASK.md` — paste this into the first Paperclip task after approving the CEO strategy.

The full product scope remains in:

- `../requirements/AI_Engineering_COE_MVP_Requirements_Baseline_v0.1.md`
- `../requirements/AI_Engineering_COE_Role_Skill_Matrix_v0.1.md`
- `../../temp/AI_Engineering_CoE_578_Item_Disposition_Register_v0.2.md`

The Paperclip execution requirements promote those three inputs into one controlled implementation contract. If they conflict, the precedence rules in the Paperclip company requirements apply.
